# AI Usage Tracker v0.1.0

The first release. A small desktop widget that shows how much of your AI coding
allowance is left, for Claude Code, Codex and GitHub Copilot, without opening a
CLI or an IDE panel.

## What it shows

- **Claude**: the 5-hour session and weekly limits, a model's own weekly limit
  where your plan has one (such as Fable), and extra usage credits if they're on.
- **Codex**: the 5-hour and weekly limits.
- **GitHub Copilot**: the monthly chat, code completion and premium request
  quotas, with the raw count ("26 of 2,000"). A quota your plan doesn't include
  shows as "Not in plan", never as used up.

Each limit gets a bar that turns amber and then red as it fills, and a countdown
to its reset. Your plan shows next to the provider's name. If a provider can't
be reached, the last numbers stay on screen, greyed out, with how old they are.
With an Admin API key, Claude and Codex also show today's and this month's API
spend.

## Highlights

- **Private by default.** Nothing is read until you connect a provider in
  Settings. Sign-ins are only read, never written or logged, and only ever sent
  to the provider they belong to. Keys you type in are encrypted with your OS
  keychain.
- **Lives in the tray.** Click the tray icon to show or hide the widget.
  Right-click for Refresh, Settings and Quit.
- **Stays on top, but not over fullscreen apps.** On Windows the widget steps
  aside while a fullscreen app or presentation is running. On macOS it stays out
  of fullscreen Spaces.
- **Refreshes on its own.** Every minute while visible (you can set anywhere
  from 30 seconds to 30 minutes), less often while hidden, and right after a
  limit resets. Test connection checks a provider on demand.
- **Yours to style.** Light, dark or system theme, any accent colour, adjustable
  opacity, and reduced motion.
- **Seven languages.** English, Turkish, French, German, Italian, Russian and
  Arabic, with a right-to-left layout for Arabic.
- **Launch at login**, on Windows, macOS and Linux.

This release isn't code signed, so the first launch asks for a click-through:

- **Windows**: SmartScreen says it protected your PC. Choose **More info**, then
  **Run anyway**.
- **macOS**: right-click the app and choose **Open**, or run
  `xattr -dr com.apple.quarantine "/Applications/AI Usage Tracker.app"`.

## Getting started

1. Sign in to the tools you use, if you haven't already: `claude`, `codex`, or
   `gh auth login` for Copilot.
2. Open Settings from the widget or the tray, and turn on **Connect** for each
   provider.
3. Optionally, add an Admin API key for API spend. This is only needed if you
   pay for Anthropic or OpenAI API usage; your plan's limits don't need one.

## Known limitations

- Codex and the separate per-model Claude limit (such as Fable) are read in the
  formats their tools use, but haven't yet been checked against a live account.
  If they look wrong, please open an issue.
- Copilot's GitHub token field is confirmed to work with the token
  `gh auth token` prints; other personal access tokens are untested.
- On an unsigned macOS build, launch at login may not work.
- On Linux the widget stays on top without stepping aside for fullscreen apps.
- On Windows, fullscreen detection goes by what Windows reports, so it applies to
  every display, and games Windows doesn't treat as fullscreen won't hide the
  widget.
- Google Antigravity support is planned for a later release.
