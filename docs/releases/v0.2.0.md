# AI Usage Tracker v0.2.0

Adds Google Antigravity as a fourth provider, and fixes a few things around
installing on Linux and the Settings text.

## Antigravity

Antigravity's quotas now show next to Claude, Codex and Copilot: the 5-hour and
weekly limits of each model group (Gemini, and Claude and GPT), and your plan.

It's off by default. Turn on **Connect Antigravity** in Settings, and keep
Antigravity running: its numbers come from Antigravity itself, over a connection
that never leaves your computer, and there's no key to enter. While Antigravity
is closed, the card keeps the last numbers and says "Open Antigravity to see
usage". If it restarts, the widget finds it again on its own.

**Please treat this one as new.** It's built on the formats Antigravity's own
tooling uses and is tested against those, but hasn't yet been checked against a
real, signed-in Antigravity. Two things to know:

- Google's backend has been seen reporting a full quota however much you've
  used. A suspiciously full bar may be that, not you.
- A quota whose remaining amount isn't reported is left out rather than shown as
  used up.

If something looks wrong, please open an issue.

## Also in this release

- The Admin API key fields in Settings now say what they're for: pay-as-you-go
  API spend only. Your Claude or ChatGPT plan limits don't need one. This was
  easy to misread.
- On Linux the app's `.desktop` entry is now named so that desktops can match
  the running window to its icon.
- Releases build and attach their installers reliably; v0.1.0's did not.

Still not code signed, so the first launch asks for a click-through:

- **Windows**: SmartScreen says it protected your PC. Choose **More info**, then
  **Run anyway**.
- **macOS**: right-click the app and choose **Open**, or run
  `xattr -dr com.apple.quarantine "/Applications/AI Usage Tracker.app"`.

## Known limitations

- Antigravity, Codex, and a model's own weekly limit on Claude (such as Fable)
  are read in the formats their tools use, but haven't been checked against a
  live account yet.
- Copilot's GitHub token field is confirmed to work with the token
  `gh auth token` prints; other personal access tokens are untested.
- On an unsigned macOS build, launch at login may not work.
- On Linux the widget stays on top without stepping aside for fullscreen apps.
- On Windows, fullscreen detection goes by what Windows reports, so it applies to
  every display, and games Windows doesn't treat as fullscreen won't hide the
  widget.
